# Harbor Terminal 0.1.7

## What's changed

Fixed terminal content shifting left and clipping the prompt or first columns. When the terminal briefly exceeded its container size, browser cursor auto-reveal could scroll an outer layout container and leave that offset behind. The terminal layout now uses non-scrolling clipping boundaries while preserving xterm's internal scrollback.

Added `make test-layout` to exercise cursor auto-reveal, long input, window resizing, tab switching and entering/exiting vi. This is a general layout fix, not limited to vi. Existing SSH and tmux behavior is unchanged.

Release titles now follow the project-name + version format: **Harbor Terminal 0.1.7**, with tag **v0.1.7**. This release is marked Latest for easier discovery. The application remains preview software.

## Downloads

- `Harbor-Terminal-v0.1.7-macOS-arm64.dmg`: macOS Apple Silicon installer image.
- `Harbor-Terminal-v0.1.7-macOS-arm64.zip`: macOS Apple Silicon application archive.
- `SHA256SUMS`: SHA-256 checksums for both downloads.

The app is ad-hoc signed, not Developer ID signed or Apple notarized. macOS may display a developer verification warning. Intel macOS, Windows and Linux packages are not included. GitHub Actions remains disabled.

## Validation

Layout, scrolling and clipboard regression tests pass. Layout tests use an isolated shell configuration. macOS packaging is checked for deep strict code-signature validity and DMG/ZIP integrity, with the layout regression also run against the packaged app.

# Harbor Terminal 0.1.8

## What's changed

Local terminals now show a waiting hint before their first output. After five seconds without output, you can open a temporary terminal that skips user shell startup files. It opens in a new tab while the original shell continues running, and never edits your shell configuration. The terminal toolbar also provides this option if initialization prints output and then stalls.

Harbor does not depend on pyenv. This recovery option helps investigate slow or blocked startup scripts; it does not automatically repair them or reset the inherited environment. Some development tools may be missing from PATH. Output alone does not prove that shell initialization is complete.

Includes English and Chinese messages, documentation, and `make test-startup` for the desktop recovery regression.

## Downloads

- `Harbor-Terminal-v0.1.8-macOS-arm64.dmg`: macOS Apple Silicon installer.
- `Harbor-Terminal-v0.1.8-macOS-arm64.zip`: macOS Apple Silicon application archive.
- `SHA256SUMS`: SHA-256 checksums.

The application remains preview software. It is ad-hoc signed, not Developer ID signed or Apple notarized; macOS may display a developer verification warning. Intel macOS, Windows and Linux packages are not included. GitHub Actions remains disabled.

## Validation

39 unit tests pass, alongside clipboard, terminal layout and slow-startup recovery desktop tests. Recovery tests verify that startup configuration is skipped, the original shell remains alive and usable, and configuration files are unchanged. The packaged macOS app is also checked with the startup and layout desktop tests, strict signature verification, and DMG/ZIP integrity checks.

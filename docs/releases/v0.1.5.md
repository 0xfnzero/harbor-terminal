# Harbor Terminal v0.1.5 — Cleaner Path Highlighting Preview

## What's changed

Valid paths in styled local zsh sessions now use cyan text instead of underlines. Path prefixes and separators use the same palette color, while command highlighting and directory listing colors remain available. User shell startup files are not modified.

Quit the previous version, replace the app in Applications, then open a new local terminal to load the updated style. Existing terminal output and server-side shell styles are not rewritten.

## Downloads

- `Harbor-Terminal-v0.1.5-macOS-arm64.dmg`: Apple Silicon installer image.
- `Harbor-Terminal-v0.1.5-macOS-arm64.zip`: Apple Silicon application archive.
- `SHA256SUMS`: SHA-256 checksums for both downloads.

The application is ad-hoc signed and passes deep strict signature verification. It is not Developer ID signed or Apple notarized; macOS may still display a developer verification warning. Intel macOS, Windows and Linux packages are not included. GitHub Actions remains disabled.

## Validation

34 core tests pass, including a real zsh PTY regression test checking cyan path output without underline escape sequences. Packaged desktop tests cover local terminal operation, server management and reconnect controls. Package integrity and signature verification are checked before publication.

# Harbor Terminal v0.1.0 — Initial Preview

Harbor Terminal is an open-source SSH client and terminal emulator for managing local shells and remote servers in a tabbed desktop workspace.

## Highlights

- Saved SSH servers with local SSH config/agent, PEM keys, key passphrases, passwords, OTP and SSH certificate support.
- Automatic SSH reconnect, keepalives and remote tmux persistence; optional Mosh for predictive echo and network recovery.
- In-app Mosh setup with configurable UDP ports (default 60042), optional authorized admin installation and targeted UFW/firewalld rules.
- Optional encrypted server profiles, app lock password and macOS Touch ID integration. Independent session keys allow existing tabs to reconnect while the interface is locked.
- English by default, with instant Chinese switching and a saved language preference.
- Six terminal themes, custom palettes and fonts, native PTYs, xterm.js and active-tab WebGL rendering.

Extract the ZIP to obtain `Harbor Terminal.app`. This preview is unsigned and not notarized; macOS may require approval before running it. Windows/Linux local build commands are provided; only the assets actually attached to this release are downloadable binaries.

## Validation

The current source passed 28 local automated tests and the terminal, security and language desktop UI suites on macOS. Language switching preserves the original Shell PID. Security tests cover encrypted persistence, lock/unlock, tamper rejection, key separation and continued reconnect attempts while locked. Local SSH/Mosh fixtures exercise latency and recovery.

These results do not establish long-term availability on every network. Physical Touch ID verification and Windows/WSL installation, UAC and reboot recovery still need device-specific acceptance. Builds and tests are performed locally; GitHub Actions is disabled for this repository.

## Important limitations

- Mosh is optional and requires UDP reachability; cloud security groups are not automatically changed. Default single-port operation allows one simultaneous Mosh connection per server.
- Persistent remote tasks require tmux. Reopening the application creates new tab/session identifiers; older tmux sessions can be attached manually.
- SSH passwords, OTPs and private-key passphrases are not saved. External PEM files retain their own protection.
- Background reconnect requires per-session keys in memory; app locking is not protection against a fully compromised operating-system account or process-memory access.

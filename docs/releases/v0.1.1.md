# Harbor Terminal v0.1.1 — Branding & Build Tools Preview

## What's new

- A new Harbor application icon, with macOS ICNS, Windows ICO and Linux PNG assets. Development launches also set the macOS Dock icon at startup; restart an already-running development app to apply it.
- A Makefile: `make` lists commands and descriptions; `make dev`, `make start`, `make test-all` and platform packaging targets simplify local development.
- `make pack` selects the host platform. `ARCH=native|arm64|x64` and `OUT=...` configure architecture and output. Build on the target operating system; packaging never publishes automatically.
- A portable development launcher that sets the Electron environment on Windows as well as macOS/Linux.
- Single focus borders for input fields and dropdowns, plus matching English and Chinese README screenshots with demo-only terminal content.

## Downloads

- `Harbor-Terminal-v0.1.1-macOS-arm64.dmg`: Apple Silicon disk image; drag the app to Applications.
- `Harbor-Terminal-v0.1.1-macOS-arm64.zip`: Apple Silicon application archive.
- `SHA256SUMS`: SHA-256 checksums for both downloads.

This preview is unsigned and not notarized. Windows and Linux packaging commands are included, but native packages and device acceptance for those systems are not part of this release. GitHub Actions remains disabled.

## Validation

28 local automated tests passed. The default Make help, packaging argument validation and focus styling were checked; the macOS ARM64 DMG and ZIP were built locally with the new icon. Existing SSH/Mosh, encryption and recovery limitations from v0.1.0 still apply.

# Harbor Terminal v0.1.2 — Terminal Experience & Input Protection Preview

## What's new

- Conventional local shell colors for directories, links and executables, colored prompts and bundled zsh syntax highlighting. Shell styling uses app-owned startup files without editing user dotfiles; remote shell colors remain server-controlled.
- Keyboard and right-click copy/paste, select all, terminal search, clear scrollback, scroll to bottom and modifier-click web links. Ctrl+C remains a shell interrupt.
- Redesigned context menu and multiline paste confirmation, with keyboard navigation and matching dark styling.
- Pasting clears an old terminal selection. Styled local zsh sessions no longer show pasted text with a misleading inverse selection background.
- Normal cross-application clipboard support, optional clipboard expiry and ownership-aware cleanup on lock/exit. Timed cleanup is off by default.
- macOS Secure Keyboard Entry follows window focus. Clipboard history exclusion hints are supplied where supported; these are best-effort protections, not a guarantee against malware or a compromised operating system.
- English/Chinese settings and documentation, plus `make test-terminal` for terminal interaction checks.

## Downloads

- `Harbor-Terminal-v0.1.2-macOS-arm64.dmg`: Apple Silicon installer image.
- `Harbor-Terminal-v0.1.2-macOS-arm64.zip`: Apple Silicon application archive.
- `SHA256SUMS`: SHA-256 checksums for both downloads.

This preview is unsigned and not notarized. Intel macOS, Windows and Linux native packages are not included in this release. Windows/Linux build commands remain available; native acceptance is still pending. GitHub Actions remains disabled.

Restart the app and open a new local terminal to load the updated shell styling.

## Validation

`make test-all`: 32 core tests plus desktop, security, bilingual UI and terminal interaction suites. Coverage includes SSH/Mosh interruption recovery in local fixtures, encrypted storage and locked reconnect, real zsh paste styling, clipboard ordering, context menu actions, multiline cancellation, Ctrl+C and macOS secure keyboard focus handling. These tests do not establish indefinite network availability.

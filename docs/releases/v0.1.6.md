# Harbor Terminal v0.1.6 — Server Actions & Scrolling Preview

## What's changed

- Server rows now have a transparent, hover-revealed three-dot menu with New, Edit and Delete actions. Clicking a server activates its most recently created open tab; New always opens another tab. Deleting a saved connection does not close its running tabs.
- Fixed main-process resize errors when a terminal's native descriptor closes before its exit callback. Reconnection and exit handling retain ownership of session state.
- Full-screen terminals without mouse reporting preserve multi-line wheel movement, including trackpad fractions and direction changes. Applications that enable mouse reporting retain their own protocol.
- Sparse terminal output is delivered immediately instead of always waiting for an 8 ms batch. Sustained output remains batched and bounded by backpressure. Remote editor redraws still depend on network latency.
- Styled local Bash disables Readline active-region highlighting where supported, while retaining bracketed-paste protection. Remote Bash instructions are documented; installing this release does not automatically change remote shell configuration.
- Added server-menu, PTY exit-race and scrolling regression tests, available through Make targets.

## Downloads

- `Harbor-Terminal-v0.1.6-macOS-arm64.dmg`: Apple Silicon installer image.
- `Harbor-Terminal-v0.1.6-macOS-arm64.zip`: Apple Silicon application archive.
- `SHA256SUMS`: SHA-256 checksums for both downloads.

The application is ad-hoc signed, not Developer ID signed or Apple notarized. macOS may display a developer verification warning. Intel macOS, Windows and Linux packages are not included. GitHub Actions remains disabled.

## Validation

All 37 core tests pass. Desktop regression suites cover terminal operation, security, language switching, clipboard behavior, tmux setup, application quit, server actions, PTY exit races and scrolling. The packaged application is checked separately, along with archive integrity and deep strict code-signature verification.

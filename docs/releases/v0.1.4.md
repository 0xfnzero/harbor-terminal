# Harbor Terminal v0.1.4 — macOS Signing & Quit Fixes Preview

## Fixes

- Fix invalid macOS bundle signatures by ad-hoc signing the completed application, including its helpers and native modules. Exclude dangling documentation symlinks from the packaged syntax-highlighting runtime.
- macOS Make packaging commands now require `codesign --verify --deep --strict` to succeed.
- Fix quit cleanup ordering: postpone vault disposal until final shutdown, resume quitting outside the native callback cycle, and share pending clipboard cleanup across repeated quit requests.
- Bound clipboard cleanup to one second so stalled clipboard access cannot indefinitely block exit. Do not recreate a window during shutdown.
- Add `make test-quit` to verify native quit with an active local terminal and normal, delayed or stalled cleanup; include it in `make test-all`.

## Downloads

- `Harbor-Terminal-v0.1.4-macOS-arm64.dmg`: Apple Silicon installer image.
- `Harbor-Terminal-v0.1.4-macOS-arm64.zip`: Apple Silicon application archive.
- `SHA256SUMS`: SHA-256 checksums for both downloads.

Quit the previous version, then replace Harbor Terminal in Applications with this version.

The application is ad-hoc signed, not Developer ID signed or Apple notarized. Signature integrity verification is not Apple approval; macOS may still display an unidentified-developer warning. Intel macOS, Windows and Linux packages are not included in this preview. GitHub Actions remains disabled.

## Validation

34 core tests and the desktop, security, language, terminal, component and quit suites pass. The signed application passes deep strict signature verification. The installed fix was also checked through the macOS Quit menu: its main and helper processes exited.

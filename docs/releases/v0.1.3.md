# Harbor Terminal v0.1.3 — One-click tmux Setup Preview

## What's new

- Install server-side tmux from **Components → tmux** using a saved SSH connection. Check availability without installing, or confirm installation from the server's package repository.
- Supports Debian/Ubuntu, Fedora/RHEL and Alpine with root or sudo access. Existing tmux is reused; existing sessions and firewall rules are not changed.
- Once ready, **Enable persistence and connect** saves the persistent-session setting and opens SSH using the original connection account. An alternate installation account does not replace the saved login account.
- tmux is explicitly server-only. The local installation selector is hidden, and switching from Mosh to tmux resets the installation target to the server.
- Correct tmux tab labels, clearer missing-component guidance and bilingual setup instructions.
- `make test-components` tests the SSH component setup workflow and is included in `make test-all`.

## Downloads

- `Harbor-Terminal-v0.1.3-macOS-arm64.dmg`: Apple Silicon installer image.
- `Harbor-Terminal-v0.1.3-macOS-arm64.zip`: Apple Silicon application archive.
- `SHA256SUMS`: SHA-256 checksums for both downloads.

This preview is unsigned and not notarized. Intel macOS, Windows and Linux packages are not included; their native acceptance remains pending. GitHub Actions remains disabled.

## Validation

34 core tests and the desktop, security, language, terminal and component UI suites pass. The component suite uses real OpenSSH with an isolated server fixture and stub package tools to verify detection, installation consent, original-account connections and stable reconnect targets. Permission denial and package failures are covered in isolated tests.

A separate client UI check using an authorized remote root account detected tmux 3.7b and verified the existing-installation reuse path. It did not reinstall packages or modify running development tasks; fresh installation and non-root sudo were not tested on that live server.

# Harbor Terminal 0.1.9

## What's changed

- Fix macOS PTY descriptor leaks after terminal exits, failed starts and repeated SSH reconnects. Native PTY dependencies are rebuilt with the fix, and packaged applications must pass resource and reconnect checks before archives are generated.
- Keep retrying temporary SSH network failures with backoff, but stop automatic retries for explicit authentication or host-key verification failures. Correct the connection settings or verify the host, then reconnect manually.
- Drag server rows and terminal tabs to reorder them, with a floating preview, animated placement, edge scrolling and Escape cancellation. Server order persists across restarts, including encrypted profiles; tab moves preserve active sessions.
- Scroll overflowing terminal tabs with a mouse wheel, trackpad or navigation arrows. The active tab stays visible when opening tabs or resizing, and the new-terminal button remains accessible.
- Avoid accessing macOS Keychain during routine security-status checks. Storage availability is checked when explicitly enabling or using Touch ID.

## Downloads

- `Harbor-Terminal-v0.1.9-macOS-arm64.dmg`: macOS Apple Silicon installer.
- `Harbor-Terminal-v0.1.9-macOS-arm64.zip`: macOS Apple Silicon application archive.
- `SHA256SUMS`: SHA-256 checksums.

The application remains preview software. It is ad-hoc signed, not Developer ID signed or Apple notarized; macOS may display a developer verification warning. Intel macOS, Windows and Linux packages are not included. GitHub Actions remains disabled.

## Validation

All 40 unit/integration tests pass, along with the full `make test-all` desktop suite and the 13-tab overflow regression. The signed application also passes 600 terminal exits, 100 failed starts and 20 UI tab closes without leaking PTY descriptors, plus repeated SSH failure, network recovery and authentication-error checks.

The packaged application passes dragging, tab overflow, terminal layout and slow-startup recovery tests. Strict deep signature verification, DMG checksum verification and ZIP integrity checks also pass.
